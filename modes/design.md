# Design
Produce an actual design artifact that serves the user's intended audience and task. Establish the relevant reference, visual hierarchy, interaction constraints and acceptance criteria from current evidence. Preserve existing design language when required; do not infer success from source changes alone.

Build a coherent first artifact before generating variants. Render and inspect it at the actual target size and important states. Compare relevant references directly; test usability, legibility and interaction where applicable. Address the highest-impact observed defect, preserving successful parts.

Deliver the editable artifact, rendered evidence, relevant checks and remaining uncertainty. Done means the requested artifact exists and has been inspected in its intended context; state any missing device, user or artistic acceptance explicitly.
