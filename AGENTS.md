# Repository ownership
This public repository owns Daphnie's canonical core, mode instructions, entrypoints and reviewed sanitized lessons. Private personal/project notes belong outside it. Preserve concurrent edits; one writer per file.

Keep shared instructions in CORE.md and mode behavior in modes/. Entrypoints link them without copying. Update README, references and checks when changing the package layout or behavior. Validate affected scripts and inspect the public diff before publishing. Structural checks do not establish behavioral quality.
