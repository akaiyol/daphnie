# Repository ownership
This public repository owns Daphnie's canonical core, mode instructions, entrypoints and reviewed sanitized lessons. Private personal/project notes belong outside it. Preserve concurrent edits; one writer per file.

Keep shared instructions in CORE.md and mode behavior in modes/. Entrypoints link them without copying. Update README, references and checks when changing the package layout or behavior. Validate affected scripts and inspect the public diff before publishing. Structural checks do not establish behavioral quality.

Each flavour owns libraries/<flavour>/manifest.json and its procedures. Preserve the protected core and flavour contracts during routine learning. Follow ARCHITECTURE.md and evaluation/PROTOCOL.md for scoped candidates, verified releases, transfer and rollback. Keep private evidence and acceptance datasets outside the public repository. Public tests are development material, not protected acceptance evidence. Run the package checker and evaluator unit tests before publishing changes to this system. Never describe synthetic gate tests as validation of live agent behavior or host isolation.
